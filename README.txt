STARK PHONE (Androidホームランチャー)

【APKの作り方A: GitHub Actions(Android Studio不要)】
1. GitHubで新しいリポジトリを作る
2. このフォルダの中身を全部アップロード(.githubフォルダも忘れずに)
3. Actionsタブ → build-apk が終わるのを待つ(5分前後)
4. 完了した実行の「stark-phone-apk」をダウンロード → 解凍 → app-debug.apk をスマホに入れてインストール

【APKの作り方B: Android Studio】
このフォルダを開く → Build → Build APK(s)

【使い方】
インストール後、ホームボタンを押すと「常に使うアプリ」を聞かれるので Stark Phone を選ぶ。
